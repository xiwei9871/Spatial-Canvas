Registry V1 is scoped to one source resource/revision/hash. Each binding maps a semantic entity_id to an explicit adapter/native_id pair and metadata. Duplicate semantic or native mappings reject the registry. Registry UUIDs are independent of object names. Frozen entity mutability is always false. Future source revisions require deliberate registry updates; there is no automatic rename matching.

Context V1 combines existing resulting-state selection, generic resource identity, source locator/revision/SHA/authority, selected entity metadata, current view snapshot and an optional actual pointer hit. Proxy coordinates remain meter/Y-up; source-coordinate conversion must be declared and checked. Missing/old hits are represented by null, never a guessed center. No packet authorizes source mutation.
