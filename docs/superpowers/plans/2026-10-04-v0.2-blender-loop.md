# Spatial Canvas V0.2 Blender Loop Implementation Plan

**Goal:** Prove the offline authoritative Blender source → derived proxy → web intent → Blender mutation → revision bump → re-export loop with stable identities.

**Architecture:** `adapters/blender/common.py` owns persistent scene/entity metadata and explicit Y-up/meter conversion. `export_proxy.py` makes temporary export duplicates and writes a V0.1 manifest without mutating source geometry. `apply_intent.py` validates the complete request before changing any object, bumps the persistent revision, saves the `.blend`, and emits a separate execution-result document. TypeScript extends the protocol package with the result contract while the existing workspace remains transport-free.

**Tech Stack:** Blender 5.2.1 headless Python API, TypeScript/Zod/JSON Schema, Vitest, Three.js GLTFLoader.
