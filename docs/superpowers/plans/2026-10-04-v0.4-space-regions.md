# V0.4 Space / Region Semantics Implementation Plan

> Execute inline with executing-plans; independent reviewers and the two packet-only agents are the only delegated tasks.

**Goal:** Resolve actual clicked locations to independently sourced spaces and explicitly gate incomplete project semantics.

**Architecture:** Zod contracts define independent versioned registries; pure core modules implement geometry and readiness. Workspace imports local project/registry files and produces optional spatial ContextPacket context; CLI adapters inventory exact local sources and normalize evidence.

**Tech Stack:** TypeScript, Zod, Vitest, polygon-clipping, Python read-only source inventory, Three.js Workspace.

- [x] Create packages/protocol/regions.ts (finite polygon geometry checks) and packages/protocol/spaces.ts (registry/project/status/result schemas). Public schemas: spaceRegistrySchema, projectSchema, semanticStatusSchema, spatialContextSchema.
