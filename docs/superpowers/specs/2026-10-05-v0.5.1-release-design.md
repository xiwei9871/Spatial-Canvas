# V0.5.1 release closeout

Issue #11 is the approved scope; existing semantics, relationship vocabulary and protocol schema names are frozen. Use the merged V0.5 baseline, an isolated worktree and one PR. No V0.6 features, source mutation, authentication configuration or automatic merge.

## Safe state and handoff

Replace ad hoc retained import state with a small pure semantic-state helper. Failed spaces/project replacement clears prior spatial semantics and dependent graph trust; failed graph replacement clears the graph only. Failed proxy replacement may retain the valid physical scene, but clears semantic trust. Design/source/revision/SHA changes invalidate incompatible semantic data; async import generations cannot commit late results. Valid same-source full/task reloads preserve only compatible metadata. Specific rejection messages explain expected/actual revision/design/hash and an action. Partial/missing semantics still produce an object ContextPacket.

One generic Copy AI Handoff action formats a short packet-only prompt plus the exact same current ContextPacket snapshot used by copy/export. The prompt distinguishes derived proxy/source authority, verification, missing evidence and edit authorization. Clipboard denial reveals a selectable read-only text fallback and download action; selection and packet remain intact. UI feedback distinguishes reading, validating, loaded and rejected states. No provider SDK or backend.

## Repeatable onboarding

Generic project templates are examples with candidate/default-unreviewed semantics and placeholder hashes; they never auto-load as reviewed project facts. A machine checklist and practical onboarding guide cover source inventory, identity strategy, full/task proxy, spaces, typed graph, scoped readiness, real click and packet-only AI review.

An umbrella CLI initializes a new folder from explicit source ID/revision/authority/frame, inspects configuration and validates supplied artifacts. It reuses protocol/runtime checks, GLB preflight, semantic ingestion and compact graph/space queries. It summarizes source/identity/proxy/spatial/relationship/manual gates and actions; missing files are gaps rather than crashes. Native source export remains the existing offline adapter boundary. init never overwrites a project/source. CLI reads real source bytes, validates frozen bindings and proxy provenance, exact registry/graph bytes and packet correspondence; no source geometry editing. Manual click/AI evidence remains manual and explicit, not silently synthesized.
