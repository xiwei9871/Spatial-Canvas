# Spatial Canvas V0.1 design

Implementation of the user-confirmed boundaries in [Issue #1](https://github.com/xiwei9871/Spatial-Canvas/issues/1). Protocol first; all proxy geometry is derived; source edits belong to future adapters.

Use TypeScript, Vite, Three.js, and Zod with generated JSON Schema. One npm project keeps setup simple. `packages/protocol` defines contracts and GLB preflight checks; `packages/core` defines selection and intent behavior; `packages/viewer` handles Three.js rendering and metadata mapping; `apps/workspace` composes the local UI. No server API or live integration.

Stable design/entity IDs and source revision linkage are required on selectable node extras. Object names are cosmetic. Structural nodes can inherit the closest explicitly identified ancestor, allowing multiple meshes per entity without inventing identities. Reject unbound meshes and duplicate explicit entity IDs. Manifest declares scope (`full` or `task`) using one shared schema. glTF geometry remains Y-up, meters; optional source frame describes a tool's original coordinates. World matrices and world bounding boxes are exposed after loading.

Local file loading chooses the manifest and its referenced self-contained GLB together. Built-in fixture loads through the same validation path. Reload rereads a newly chosen export; same-design selections survive only for IDs still present and generate an updated event. A failed reload keeps the last valid scene. The inspector and event panel expose metadata and exact validated JSON. Transform requests are world-frame translation deltas against a specific source revision; they do not move scene geometry or call an adapter.

Automated checks cover malformed manifests, versions, source revisions, identity binding, GLB structure, selection transitions, request boundaries, and JSON Schema parity. Browser verification covers actual raycast selection, multi-select, file loading/reloading, error recovery, and intent generation. Generated working artifacts are ignored; the small reproducible fixture is explicitly allowed.
