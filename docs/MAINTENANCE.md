# Maintenance Mode

Spatial Canvas is functionally complete for the current product goal after V0.5.1 merges. The stable scope is selection, frozen-source ContextPacket, independent space semantics, typed relationship context, safe import failure behavior, onboarding and packet-only AI handoff.

Maintenance work is limited to concrete bug fixes, compatibility updates, security fixes and small usability improvements exposed by a real project workflow. New semantic domains, relationship vocabulary, live sync, graph visualization, cloud services, agent backends and speculative roadmap items require a separately approved future task. This document describes the post-merge state; until the closeout PR merges, the branch remains under review.
