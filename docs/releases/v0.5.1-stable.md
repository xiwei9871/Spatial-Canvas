## Workflow and boundaries

Load Proxy → import semantics/relationships when needed → select → Inspector → Frame/Hide/Ghost → adjust or restore view → Copy AI Handoff. Precise camera/temporary visibility reproduction additionally uses the already saved View Handoff or preset JSON + reference PNG.

- Source/revision/SHA is pinned and must be checked against actual source bytes before offline execution.
- Inspector, Space / Region and Relationships answer different questions; candidate/unresolved regions are not verified facts.
- Missing relation evidence is not permission to infer connections, adjacency or functional topology.
- Hide/Ghost and saved-view changes are viewer state; adapter camera snapshots must remain separate from authoritative sources.
- ContextPacket/AI Handoff is context, not source-edit authorization, and does not include hidden/ghost IDs; those belong to ViewPreset.
- No live sync, backend/cloud platform, provider orchestration or speculative V0.6 roadmap is included.
